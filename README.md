# Face Blur

## Цели проекта

- Создать локальный инструмент для обработки видео: находить лица в кадре, размывать их и сохранять результат в MP4 с исходным звуком.
- На практике освоить OpenCV, PyTorch, YOLO и инструменты для обработки видео.
- Изучить и сравнить три подхода: готовый детектор YuNet, обучение модели на PyTorch и дообучение YOLO.

## Этапы

1. Подготовить окружение и настроить чтение, нормализацию и сохранение видео.
2. Подключить YuNet и реализовать первое размытие лиц.
3. Подготовить данные WIDER FACE и конвертировать разметку.
4. Обучить учебную модель на PyTorch и дообучить YOLO.
5. Оценить качество детекторов и сравнить результаты.
6. Добавить трекинг лиц между кадрами и проверить стабильность размытия.
7. Измерить производительность и оптимизировать обработку.
8. Создать локальный интерфейс и упаковать приложение в Docker.
9. Провести финальную проверку и записать демонстрацию.
